# Agify Make app

Production-ready local Make custom app for the Agify API at `https://api.agify.io`. Authentication uses the documented `apikey` query parameter.

Included modules (3 total including the universal fallback):

- Make an API Call
- Predict Age
- Predict Ages in Batch

No webhooks are included because Agify exposes a prediction API and no webhook registration lifecycle endpoints.

Docs: https://agify.io
